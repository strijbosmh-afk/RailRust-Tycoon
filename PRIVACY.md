# Parkbound privacy

Parkbound runs offline. The game stores parks, campaign progress, track designs,
scenarios, display preferences, accessibility preferences and sound settings on
your computer. The usual location is `%LOCALAPPDATA%\Parkbound\saves`.

The game sends no analytics, advertising identifiers, crash reports or park data.
Diagnostics run when requested and write their results to the location you choose.
The Windows installer contains its game files and runtime dependencies.

You choose whether to share a park, screenshot or diagnostic report. Review a
report before posting it. File paths can contain your Windows account name, and
parks can contain names you have entered. GitHub has its own privacy policy when
you visit the project or submit an issue.

Uninstalling the program preserves player data. To remove it, close Parkbound and
delete the player-data folder yourself. If you have used `--save-dir`, that chosen
directory holds the data for that launch.
