# Campaign awards and unlocks — 0.70.0

Open **Guests [L] → Scenarios**. A new park starts in Sandbox. **Meadow Challenge** is the first campaign challenge. Win it by reaching 20 new visitors, five completed ride visits and $750 cash together. The game records the Meadow award and unlocks **Boardwalk Sprint** for a separate park. Boardwalk then asks for 24 new visitors, 12 completed ride visits and $900 cash within ten simulation minutes. Winning it records the Boardwalk award. Both awards appear in the Scenarios pane. The same park still accepts only one challenge; close and reopen the game for a fresh park or load an earlier sandbox save.

The awards belong to the player, not to one park save. They are stored in `%LOCALAPPDATA%\Parkbound\saves\campaign.json`, with `campaign.json.bak` as the previous valid record. Park saves remain separate `park.park.json` and `park.park.json.bak` files. To continue on another Windows PC, close Parkbound and copy whichever of these four files exist in that folder; backup files appear after a later write. The shared OneDrive source checkout alone does not carry player saves or awards. The exact source path and build steps are in [RESUME_DEVELOPMENT.md](../RESUME_DEVELOPMENT.md). If you launch with `--save-dir`, the campaign files live in that chosen folder beside the park files.

A completed challenge loaded from an older park save can still grant its missing award. An already earned award is not written a second time. A Boardwalk win from an older save also keeps Boardwalk access even if there is no Meadow record. If the campaign record is damaged, the game reads its backup and shows a recovery notice. If neither copy is usable, or the primary record uses a newer version, it blocks campaign starts and reports the problem instead of replacing the files. Sandbox parks and old park saves remain playable.

The park save format remains **39/39** in this phase. The campaign file is a separate version-one, small, strictly checked record. This release adds an original two-challenge sequence and visible awards; it does not yet add more objective types, an editor or downloadable scenarios.
