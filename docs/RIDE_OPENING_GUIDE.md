# Opening rides to guests

Use **Rides [Y] → Operations → Open ride**, the main **Open** button, or **O** after selecting a ride. Each opening request checks the actual installed ride, its entrance and owned queue, and its exit's return path. A refusal changes no park state and explains the first problem. The Operations status also shows what needs attention before you click.

1. Finish and Apply a complete coaster draft, or build a carousel. The draft alone cannot carry guests. Track construction validates endpoints and clearance.
2. In **Rides → Access**, build the entrance beside the station/body and connect its owned queue to one public entry at the far end. Remove disconnected pieces, branches and extra public connections when the checklist requests it.
3. Build the exit beside the station/body. Continue an outward public path until it joins the queue entry's public network. Merely placing a green exit gate does not complete this return route. Use **Prepare suggested public path** repeatedly to prepare the next legal tile; move to an exposed ghost edge and click to build it. A bridge may need ramps before crossing over track.
4. Return to **Operations**. When the status says **Ready to open / access connected**, configure cars, station waits and loading, then open the selected ride. Save with **F5** after closing the panel.

The isolated coaster mechanics test stays available while closed, stopped and empty, even without gates or paths. It checks one lap and produces approximate layout metrics. It is separate from guest access readiness and does not certify real forces or safety.

Closing remains available after a path is removed. Current trips finish under the existing passenger rules; a damaged exit can hold passengers until you repair it. Reopening rechecks the current connections. There is no automatic replacement path or automatic rebuilding.

Existing saves retain their exact open/closed state and passenger journeys when loaded. Historical demonstration parks can contain an open train without guest access; closing it and trying to reopen now requires the same connections as a newly built ride. This milestone introduces no new save fields and no retroactive closure on load.
