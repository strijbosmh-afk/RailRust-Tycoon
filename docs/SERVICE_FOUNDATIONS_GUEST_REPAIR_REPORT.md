# Service foundations and guest path repair — 0.52.0

This stage makes elevated service buildings read as supported structures and gives the player an actionable route from a lost visitor to the existing path tool. Facility geometry extends four timber posts from the service deck to the terrain height when clear. A lower crossing in the same tile suppresses those posts. The posts follow the ordinary service mesh, selection, preview and static visibility pipeline. They do not alter collision, navigation or save state.

Guests [L] offers **Repair path** for a selected lost visitor. The action focuses the guest, closes the list and prepares the normal path tool at the guest's height. A missing path uses its remembered slope; an isolated existing path uses a flat join. The hint gives either the missing tile coordinates or the disconnection instruction. Preparation is read-only for the park. Construction still requires a player click and the usual validation and payment. The selected Services panel adds a live threshold count for the corresponding need, using the simulation's existing seek threshold.

This work adds no external artwork, font, asset, dependency, random draw, save field or change to the 25/25 save pair. It does not add automatic staff assistance, litter or vomit. Those remain later gameplay work. The full classic game and clean-PC acceptance remain open. This development PC is not a performance reference.
