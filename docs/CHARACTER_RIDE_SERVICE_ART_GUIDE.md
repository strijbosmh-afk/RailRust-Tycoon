# Character, ride and service art — 0.54.0

Visitors now show clearer shoes, shaded clothing, bag straps and small facial features when you zoom in. Their twelve stable looks, walking motion, selected-guest marker and lost warning still follow the same guest IDs and simulation positions. The extra detail is prepared once in reusable templates, so it does not require a new drawing calculation for every visitor on every frame.

Coaster cars have inset side panels, trim and paired front lamps. The carousel deck uses forty-eight radial pieces for a rounder edge at high zoom, with a narrow brass rim; its moving mounts have additional mane, tail and bridle details. Existing ride color choices still recolor the intended vehicle/structure parts.

Food has a small menu board, Drinks has taps and straws, Toilets has a door plaque and vents, and Rest has bench slats and a hanging light. These remain original procedural shapes. They sit inside the facilities' current one-tile, three-height-step envelopes. Select, build, preview, demolish and path access work as before.

This stage changes presentation only. Park saves remain strict **25/25**, sound settings remain separate, and no external art or font is bundled. The shared OneDrive checkout and Windows rebuild instructions are in [RESUME_DEVELOPMENT.md](../RESUME_DEVELOPMENT.md).
