### Current 0.27 copy and draft history status

The current branch is `codex/track-draft-history`, based on `925bae82076a95098aafa582b3d7a936fd6ddd28` / [PR #24](https://github.com/strijbosmh-afk/RailRust-Tycoon/pull/24). Copy live overwrites the current draft with exact installed specifications as one undoable action, even while the coaster runs or has passengers. A missing or faulted circuit leaves the plan intact. Undo [Ctrl+Z] and Redo [Ctrl+Y or Ctrl+Shift+Z] retain at most 64 actual draft edits per session. Copy, placement/replacement, erase and Clear participate; unchanged/refused actions do not add history, and a new edit after Undo discards redo.

Successful Apply clears history; refused Apply preserves it. Done, Escape and closing/reopening the editor retain the plan and stacks. Saving persists the current draft only; successful Load/Backup resets stacks while loading the saved draft. No history operation rewinds installed rails, cash, refunds, guests or simulation. Restored plans can be incomplete or obstructed and must pass current validation on Apply. Save schema/content remain 15/15.

All **224 release simulation tests** passed, including seven new copy/restore tests. Game/input, complete source, production, visual, exact-source CI and package verification remain pending, and the latest verified ZIP remains 0.26. ## Scope decisions still required

- **Catalogue audit:** confirm the complete classic ride/track/operating-mode inventory against the intended RCT1/RCT2 reference. The mechanical families above establish implementation coverage; exact ride variants, piece counts, scenery themes, and scenario counts remain undecided.
- **Expansions:** catalogue expansion-specific content separately, including Added Attractions/Corkscrew Follies, Loopy Landscapes, Wacky Worlds, and Time Twister references. Inclusion is undecided; no expansion catalogue is silently promised or silently treated as complete.
- **Compatibility:** importing original RCT parks, scenarios, designs, or saves is undecided and unnecessary for the standalone original-content target.
- **Later extensions:** multiplayer, mobile/console versions, and a scripting API are outside the current single-player Windows plan unless the user expands scope.
