# Raised path perspective — 0.49.1

The terraced park made elevated paths look as if they flowed into lower land without a visible structure. This corrective stage gives a path tile a timber bridge post when its deck is at least one height step above the ground under that tile. The post reaches that tile's actual terrain height. It is omitted where another object occupies the vertical space below the path, so it does not cut through a crossing track. Ground-level paths have no post. The same view works through all four camera rotations; the underground cutaway retains its existing presentation.

Source is on `codex/bridge-perspective-supports` in [draft PR #49](https://github.com/strijbosmh-afk/RailRust-Tycoon/pull/49), stacked on `codex/visitor-overview-find`. Runtime source commit: **`7500e0a3108b6c059d6ff8a883ac34b538ae0851`**. The ZIP stays local in `dist/`, with its adjacent SHA-256 sidecar; GitHub carries source and guides.

This is original project geometry generated by the renderer. It changes no path placement rule, guest route, picking surface, construction price, save field or random draw. Elevated paths are allowed to bridge lower ground; guests connect across two path edges only at matching endpoint heights. One-step slopes still provide transitions between heights. Save schema/content remains **24/24**.
