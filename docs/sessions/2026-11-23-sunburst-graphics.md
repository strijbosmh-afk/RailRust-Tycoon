# Sunburst Coaster graphics

- Project `railrust-tycoon`
- Session `sunburst-graphics-2026-11-23` on `MICHIEL-BUILD`, 23 November 2026 UTC
- Branch `codex/right-click-settings`, baseline `d4349bd6e65ef0b6e94ad7198ee65e5fc35d1f71`

Sunburst is the reference for an updated Classic Coaster. Its rails and car
body share a warm coral palette. The car sides have wider gold bands, timber
supports are slightly thicker, and gold gutters frame pitched platform roofs.
The queue still reads as a blue queue, with gold edges specific to this model.
The changes use the existing Windows and Rust build requirements.

The station and running train were inspected in a focused Sunhaven Gardens
capture. The work uses existing ride paint, track geometry and queue
ownership with no save migration. Changes to other landscape and visitor
features are future work.
