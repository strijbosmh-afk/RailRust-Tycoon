# Parkbound rights and redistribution status

The owner has deferred the open-source license decision while the Windows test
version is completed. The repository currently grants no general open-source
license for the original project code or assets. Public source access alone does
not grant redistribution rights.

The owner's Windows test builds are free to play with all implemented game
functions. Permission for a wider public redistribution release will be recorded
here when the owner chooses its terms.

Third-party components retain their individual licenses. Each Windows package
includes `THIRD_PARTY_NOTICES.txt`, `DEPENDENCIES.json`, font license
files and `RUST_STANDARD_LIBRARY_NOTICES.html`. Original artwork records are in
`assets/art/PROVENANCE.md` and `assets/manifest.json`.

The visitor cheering recording by AuraVoice is CC0 1.0. Its original, converted
WAV, full terms and provenance are retained in `assets/audio/` and included in
the Windows package. The music compositions and remaining effects are original
Parkbound work. See `assets/audio/PROVENANCE.md`.

The installer is built with Inno Setup 6.7.4 by Jordan Russell and Martijn Laan.
Its upstream license permits use in installers and retains its own notices.
See https://github.com/jrsoftware/issrc/blob/is-6_7_4/license.txt.
